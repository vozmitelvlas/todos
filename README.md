# Todo App

A simple and responsive task management application built with React and TypeScript.

## Features

- **Task Management** — create, edit and delete tasks
- **Priority Levels** — assign Low, Medium or High priority
- **Filtering** — filter tasks by priority
- **Completion Tracking** — mark tasks as completed
- **Confirmation Modal** — confirm task deletion
- **Loading State** — display a loader while tasks are being loaded
- **Date Tracking** — display the last update date for each task

## Tech Stack

- **React 19** — UI development
- **TypeScript 6** — static typing
- **Tailwind CSS 4** — styling
- **Vite 8** — development and build tooling
- **React Icons** — icons


## 🚀 Getting Started

```bash
# Clone the repository
git clone <repository-url>

# Install dependencies
npm install

# Start development server
npm run dev
```
