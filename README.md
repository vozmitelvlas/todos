# Todo List
### Управление задачами на React + TypeScript

## Возможности

- загрузка задач из mock API;
- фильтрация задач по приоритету;
- создание новой задачи;
- редактирование задачи;
- изменение статуса выполнения;
- удаление задачи с подтверждением;
- отображение даты последнего изменения;
- состояния загрузки и пустого списка.

## Стек
- React
- TypeScript
- Vite
- Tailwind CSS
- React Icons
